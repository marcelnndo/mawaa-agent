## Mawaa AI

> AI coding agent untuk terminal — membantu menulis kode, menjalankan perintah, mengelola file, dan bekerja langsung dengan project.

Mawaa AI adalah terminal coding agent yang dirancang untuk membantu developer menyelesaikan berbagai task menggunakan bahasa alami.

## Installation

Install Mawaa melalui npm:

```bash
npm install -g @arcelnando/mawaa

Setelah proses instalasi selesai, jalankan:

mawaa "buat fitur login sederhana"

Atau untuk memeriksa project:

mawaa "cek status git project ini"
